# Cursus reference assets

Public design reference: https://cursus-mu.vercel.app/
Captured on 2026-10-06 at the user's explicit request to reproduce that interface.

- `hero-day.mp4`, `hero-night.mp4`: original public hero videos.
- `hero-day.webp`, `hero-night.webp`: original public hero posters.
- `assistant.svg`: original public, rendered mascot SVG.
- `logo.svg`: original public favicon.

These files are archived visual-reference materials only. They are not served
or used by the HaUI Compass website. The public pages now use the project's
compass mark, original student illustration and student learning flows in
`apps/web/src/components/compass`. No Cursus application scripts, API,
authentication, provisioning or private data are used.

Fonts in `/public/fonts` are Be Vietnam Pro and Manrope from Google Fonts.
Both are distributed under the SIL Open Font License 1.1.
