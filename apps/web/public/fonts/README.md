# Local fonts

These fonts are served locally; the UI does not contact a font CDN at runtime.
The matching OFL license files are included here.

- Bitter regular: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/bitter), downloaded from `fonts.gstatic.com`.
- Instrument Serif regular: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/instrumentserif), downloaded from `fonts.gstatic.com`; used on Statistics, with Bitter for Vietnamese headings.
- Inter regular: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/inter), downloaded from `fonts.gstatic.com`.
- Manrope: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/manrope).
- Be Vietnam Pro: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/bevietnampro).

Bitter and Inter are used by the account screens. Manrope and Be Vietnam Pro
support the existing public pages and Vietnamese typography.
