## Software Project
Xây một dịch vụ quản lý danh sách việc hư cấu theo architecture module nhỏ. Sinh viên tự viết code và giải thích quyết định thiết kế; không dùng dữ liệu người thật.

Đầu ra dự kiến: source code, README hướng dẫn chạy, unit test cho domain/service, integration test cho API–repository boundary và một báo cáo ngắn về giới hạn còn lại.

## Engineering Review
Chọn một thay đổi trong project, trình bày requirement, thiết kế, test evidence và một trade-off. Không cần tạo slide hoàn chỉnh bằng AI.

Đầu ra dự kiến: review note ngắn, liên kết commit hư cấu trong demo và kết quả test có thể tái lập.
